# 初代小车 · 结构与工作原理

用于小车交接和学习。保留整个目录，直接打开 `index.html` 即可使用，无需安装依赖或连接实车。

## 从功能理解小车

桌面端采用尽量在一个视口内阅读的布局，去掉重复提示、页脚与次要小字。主页面由同一功能下的两部分组成：左侧是固定视角的实体部件示意，右侧是对应的工作流程和分步解释。无需在整车结构、电路图和单个器件说明之间来回切换。

默认从转向开始；顶部可切换整车逻辑、转向、驱动与油门、前进与后退、霍尔反馈、供电与共地。

- 顶部是唯一的功能导航；整车逻辑只展示放大的小车，不重复罗列功能入口。
- 在右侧顶部手动选择步骤，或点击“上一步 / 下一步”。下方紧接当前步骤说明，左侧只呈现部件与信号；每次点选只有短暂的强调动效，页面不会自动前进。
- 转向按“比较位置 → 下达驱动 → 机构转动 → 返回反馈 → 到位停驱”讲解。Arduino 始终是这项功能的一部分；AS5600 示意安装在转向电机上方。
- 点击左侧部件，原步骤说明区域会显示该部件的分工；点击任一步骤或关闭按钮即可返回。
- 需要核对端子时，展开“核对本功能的接线与接口”，选择一根线。左侧只突出这根线的两端；选线也会定位到相关工作步骤。桌面端在右侧同一区域切换原理与接线，结构图保持可见。
- 窄屏上下排列实体图和工作流程；较小屏幕可在图示区域横向查看，保持部件与文字可读。

分步图只解释因果顺序，不对应实车时间、角度、传感器读数或速度。AS5600 为便于辨认适当放大，仍安装在转向电机上方。RC 图中显示 1kΩ 串联后，10kΩ 与电容分别并联到公共参考地，两侧 THR 取自同一节点。网页只保存最近查看的功能，不向小车或其他外部服务发送控制指令。

## 原理与接线依据

依据原作者元器件记录、交接版《硬件与接线》《程序逻辑与维护》以及当前项目的相关记录整理。

保留原网页的 63 根电气接线记录。霍尔 5V 按用户新提供的面包板方案保留原有供电，不新增第二路并联电源。此前交接资料对上游 5V 来源的描述，不能替代实物确认。

本次按用户提供的 170 孔板方案重画面包板：每排 a～e 互通、f～j 互通，中沟两侧隔离。第 1 排 a1 接原霍尔 5V，b1 / c1 接左右轮红线；f1 接原公共地，g1 / h1 接左右轮地线。左半边跳线：e1–e3、a3–a4、b4–b5、a5–a6、b6–b7、a7–a8。第 3～8 排分别跨接 d–g 上拉电阻，h 孔接霍尔、i 孔接 Arduino、f 孔留空：左 HU/HV/HW → A1/A2/A3，右 HU/HV/HW → D10/D11/D12。

流程中的信号与能量传递使用箭头；端子接线、RC 并联支路、面包板跳线与共地使用不带箭头的连线。AS5600 的流程箭头从器件边缘外引出，核对具体端子时才显示到引脚的接线。
区分三种信息：

- 工作关系：谁控制谁、谁提供动力、谁返回反馈。
- 电气关系：端子、公共节点、并联支路和参考地。
- 实物接头：哪几条线经哪个一分三接头汇合。

已知多处使用一分三接头；具体接头归组在实物确认前不作为已知事实绘制。目前待确认：L298N GND 一分三是否分别汇合降压器 OUT−、Arduino GND、ENB 下拉电阻地端；AS5600 绿色 GND 所接的分线组；RC 下拉电阻地端与电容负极汇合后的实际去向。公共参考点只是电气关系，不代表新增接线板。

模型按照片简化，部件间距为便于理解而展开，不作为施工尺寸。AS5600 反馈电机转动位置；连杆间隙仍可能影响实际前轮朝向。霍尔用于运动和停稳判断，当前共同油门不是两轮独立的轮速闭环；撤油门也不等于主动刹车。
