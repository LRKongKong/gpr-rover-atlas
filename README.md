# 初代小车 · 结构与接线

用于小车交接与学习的交互式网页，包含整车透视、电控展开和 Arduino 引脚视图。支持逐根查看转向、油门、换向、霍尔反馈及供电线路，并提供转向机构动作示意。

## 使用

直接打开 `index.html` 即可使用。网页不需要安装依赖，不连接实车，也不向外部服务发送控制指令。查看选择保存在浏览器本地。

模型按实物照片简化，接线按功能展开，线路颜色用于区分功能。部分器件的精确型号、尺寸与原始端头信息仍可继续补充。

## GitHub Pages

在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，保存后即可发布。

后续直接更新 `index.html`，GitHub Pages 会重新部署。
